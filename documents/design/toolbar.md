## Toolbar
**Note**
1. It has two hover tips: selected and non-selected. For example: Rubberband Zoom button. 
2. If a user opens an older version, or does not have permission to edit, disable all "Edit" buttons.

**Buttons**
1. Save
2. Save Document As
3. Export Document
4. Print Document
5. Quick Download
6. Zoom In
7. Zoom Out
8. Rubberband Zoom 
9. Fit to Window
10. Fit to Height
11. Fit to Width
12. Go to First Page
13. Go to Previous Page
14. Jump to Page
15. Go to Next Page
16. Go to Last Page
17. Rotate Left
18. Rotate All Left
19. Rotate All Right
20. Rotate Right
21. Picture Controls
