## Thumbnail Right-Click Menu

*Note: All menu items are structural page-level or document-level actions. These update the document's logical state and sync with the backend operations API, rather than directly modifying the live PDF Viewer binary data.*

**Menu**
1. Select All
2. Select None
3. Add Bookmark
4. Cut
5. Copy
6. Delete
7. Insert Before (Paste Cut/Copy)
8. Insert After (Paste Cut/Copy)
9. Insert Blank Before
10. Insert Blank After
11. Export / Print (Same as Toolbar Export)
12. Split Document
